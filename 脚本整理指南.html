GF-2 土地覆盖分类项目 · 脚本整理指南

整理自 D:\gf2-landcover 文件夹 · 共 25 个 Python 脚本 · 归纳为 4 条技术路线 + 2 组工具

一、先说结论

这个文件夹是同门做的同一套任务的四种方法对比实验：用高分二号 0.8 米四波段影像，把土地覆盖分成 6 类（1 耕地 / 2 林地 / 3 草地 / 4 水域 / 5 建设用地 / 6 未利用地）。四种方法分别是：Prithvi 遥感大模型微调（主线，README 里写了完整流程）、随机森林 / SVM 像素级分类、轻量 CNN、面向对象 OBIA 分类。另外混进来 11 个跟分类完全无关的简历编辑小工具，不用管它们。

三、逐个脚本说明

路线 A：Prithvi 大模型流程（README 主线）

脚本作用输入 → 输出
01_check_bands.py第 1 步。检查影像是不是 4 波段、分辨率多少，判断波段顺序是否正确影像 tif → 控制台报告（3 波段会提示去找原始数据重做融合）
02_tile.py第 3 步。把影像和标签切成 224×224 小块，按网格划分训练/验证（防泄漏），统计各波段均值方差影像+标签 → data\tiles\train、val 下几千个小块 + data\stats.json
03_train.py第 4 步。微调 Prithvi-EO-2.0-300M（UperNet 解码头），带早停、自动存最佳模型，训练完自动跑一遍精度评估切片数据 → output\checkpoints\best.ckpt + 控制台精度报告
04_predict_scene.py第 5 步。对整幅影像滑窗推理，输出类别编号图和配色图影像+模型 → result.tif、result_color.tif（拖进 QGIS 查看）
check_labels.py数据体检。检查标签切片的数值范围/nodata/NaN，诊断训练报 bincount 错误的根因data\tiles 或指定标签文件 → 控制台诊断结论
prithvi_eval.py单独对验证集重新评价已训练的 Prithvi 模型（不用重新训练）best.ckpt + 验证切片 → OA/Kappa/分类报告
extract_metrics.py解析 TensorBoard 训练日志，对比每一次训练运行的损失和指标曲线，确认哪个检查点最好output\gf2_landcover\version_* → 控制台各轮指标汇总

路线 B：随机森林 / SVM（对应你 D:\gf2 的数据）

脚本作用输入 → 输出
rf_train.py就是生成你那张 RF_result_corrected.tif 的脚本。分块随机采样 50 万训练像素训练 RF，再分块预测整幅图train_area8.tif + train_label13.tif → RF_result_corrected.tif + 精度报告
svm_train.py同一套流程换 SVM（RBF 核，含特征标准化、类别权重平衡），样本量小很多因为 SVM 慢同上 → SVM_result_corrected.tif + 精度报告
align_rf.py用最近邻重采样把分类图对齐到标签栅格的网格/投影上（评价前必须对齐）任意分类图 → RF_aligned.tif
rf_eval.py对齐之后，随机抽 200 万像素算 OA/Kappa/混淆矩阵，属于独立复评train_label13.tif + RF_aligned.tif → 控制台精度报告
merge_tiles.py把其他试验区（area2、area7）切好的块复制合并进主训练目录，用于扩样本tiles_area*_clean → data\tiles\train、val

路线 C：轻量 CNN 对比

脚本作用输入 → 输出
cnn_train.py自建的 6 层小编码-解码网络，一个脚本完成训练、验证评价、整图推理三件事；检测到已有模型权重就跳过训练直接推理data\tiles 切片 → cnn_best.pth、result_cnn.tif + 精度报告

路线 D：面向对象分类 OBIA

脚本作用输入 → 输出
gf2_landcover_obia_classification.pySLIC 超像素分割 → 提取对象的光谱+纹理特征 → 对象级 RF 训练 → 整幅分类。整幅载入内存，对电脑配置要求高train_area8.tif + labels9.shp（你标的）→ obia_output\
gf2_landcover_obia_tiled_classification.py上面的分块版：每次只处理 1024×1024 带缓冲的小窗口，内存占用大幅降低，全幅约 20 亿像元但可以慢慢跑完同上 → obia_tiled_output\

六、快速上手（按你想做的事查）

  • 想跑通主线（大模型分类）：读 README.md → conda activate prithvi → 按第 0~5 步依次执行 01→02→03→04
  • 想重训随机森林：改 rf_train.py 开头的三个路径，直接 python rf_train.py
  • 想评价新的分类结果：如果和标签网格不一致先跑 align_rf.py，再改 rf_eval.py 里的 PRED_PATH 运行
  • 想跑面向对象分类：用分块版 python gf2_landcover_obia_tiled_classification.py（标签就是你标的 labels9.shp）
  • 想看某次训练效果如何：python extract_metrics.py（注意：脚本里的路径还写的是老的 C:\gf2-landcover，要先改成 D:\gf2-landcover）

小提醒：不少脚本里写死了 D:\gf2\... 或 C:\gf2-landcover\... 这样的绝对路径，换电脑或挪文件夹后要打开脚本改开头"配置区"的路径才能跑。

七、和学习指南的关系

README 提到的"学习指南第 5/6 章"是同门自己写的 Prithvi 环境安装和官方示例教程（本文件夹里没有，应该在别处）。类别方案（1 耕地、2 林地、3 草地、4 水域、5 建设用地、6 未利用地）与你 D:\gf2 的 labels9 标签一致，四条路线的精度可以直接对比。数据流水线的公共部分是：影像 + 标签 →（02_tile 切片）→ 各种模型 → 分类图 → 精度评价。
